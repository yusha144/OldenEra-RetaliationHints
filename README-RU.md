# Olden Era — Retaliation Hints 0.1.0

Отдельный мод с предварительной оценкой потерь от ответного удара. Работает рядом с Map Hints и Skill Synergies, не заменяя их файлы. Первая версия для проверки в игре пользователем; это ещё не полная симуляция всех боевых событий.

## Что появится в бою

При наведении на противника, когда игра показывает прогноз атаки, под полоской атакующего отряда появляется иконка погибших бойцов и надпись:

- `Ответка ~ 2-5`: предварительная оценка от двух до пяти погибших бойцов своего отряда.
- `До атаки ~ 2-5`: враг имеет упреждающую ответку; его численность ещё не уменьшена вашей атакой.
- `Ответки нет`: штатная проверка игры запрещает ответный удар или его заряды исчерпаны.
- `Ответка: расчёт недоступен`: числовую оценку для этого случая получить нельзя. Это не нулевые потери.

Текст использует шрифт игры, подсказка прикреплена к штатной полоске отряда, не перехватывает мышь и скрывается с прогнозом атаки. Собственного окна поверх меню и горячих клавиш нет.

## Что учтено

Исходящий урон берётся прямо из текущей подсказки игры. Для ответного удара используется та же штатная функция расчёта с текущими характеристиками, действующими модификаторами героя, фракции и эффектов, которые уже входят в расчёт игры. Учитываются защита, тип ответной атаки, её основной множитель, раненый верхний боец и оставшееся после первого удара количество врагов. Возможность контратаки проверяет сама игра. Упреждение определяется по активному эффекту, а не по имени существа.

## Границы первой версии

Знак `~` означает оценку, а не гарантированные пределы результата боя. Случайная удача/неудача, новые эффекты после попадания, изменение аур после передвижения, вампиризм, дополнительные удары, реакции других отрядов и атаки по пути пока не моделируются. Они могут изменить фактические потери за пределами показанного диапазона. Прогноз относится к одному ответному удару выбранного врага, а не ко всем потерям за ход.

Для временных существ и защиты от смертельного урона числовая оценка отключена: простого вычитания здоровья для них недостаточно. Неизвестная схема атаки также не выдаётся за ноль. Эта версия не подходит для обещания точного прогноза любых сочетаний законов, перков и заклинаний.

## Установка и проверка

Поддерживаемая сборка игры: Steam 25672315, Unity 6000.0.66, установленный BepInEx 6.0.0-be.788 IL2CPP. При несовпадении контрольных сумм игры мод отключается.

Файл мода: `BepInEx/plugins/RetaliationHints/OldenEra.RetaliationHints.dll`.
Настройки: `BepInEx/config/local.oldenera.retaliationhints.cfg`.
`Enabled` включает отображение, `TextScale` регулирует размер текста. Изменения файла настроек применяются после перезапуска игры.

После установки самостоятельно перезапустите игру. В обычном бою или бою Арены выберите свой отряд и наведите курсор на противника, доступного для атаки. Проверьте появление надписи под своим отрядом и исчезновение при уходе курсора с цели. Затем сравните прогноз с ответкой в простом случае без удачи и срабатывающих эффектов. Отдельно полезны цель, погибающая от первого удара, цель с израсходованной ответкой и упреждающий удар.

Игра для проверки разработчиком не запускалась и не управлялась. Проверены сборка, отдельная арифметика потерь и множители контратак в установленной базе. Отображение и подключение к живому бою ещё требуют пользовательской проверки.

Журнал диагностики: `BepInEx/LogOutput.log`, строки `Retaliation Hints`. Успешное первое отображение отмечается отдельной строкой. При ошибке мод не подменяет её нулевыми потерями.

Для отключения достаточно установить `Enabled = false` при закрытой игре. Для удаления — удалить только папку `RetaliationHints` из `BepInEx/plugins`. Файлы других модов менять не нужно.

## Сборка

`dotnet build source/RetaliationHints.csproj -c Release`

`dotnet run --project tests/RetaliationHints.Tests.csproj -c Release -- "путь к HeroesOldenEra_Data/StreamingAssets/Core.zip"`

В проекте указан локальный путь игры; на другом компьютере задайте `-p:GameRoot="путь к игре"` при сборке. Библиотеки игры и загрузчика в исходники не включены.

Мод только читает живое состояние боя. Для пересчёта ответки копируются объекты и отдельно отделяются изменяемые поля здоровья и позиции. Мод не наносит урон, не выполняет игровые команды, не расходует генератор случайных чисел и не меняет сохранения. Архив и история остаются локальными.
