# Установка и удаление Retaliation Hints

## 1. Требования и статус

Тестовая версия 0.1.13 содержит неполный расчёт ответного удара. Перед использованием прочитайте [ограничения](../README.md#ограничения). Число в подсказке является приблизительным прогнозом.

Нужны Windows x64 и установленная Heroes of Might and Magic: Olden Era, Steam build 25672315. Для первой установки нужен интернет: установщик скачивает BepInEx Unity.IL2CPP 6.0.0-be.788 и библиотеки Unity 6000.0.66 с серверов BepInEx, проверяет SHA-256. Совпадающие установленные зависимости повторно не скачиваются.

## 2. Установка

1. Скачайте [OldenEra-RetaliationHints-0.1.13.zip](https://github.com/yusha144/OldenEra-RetaliationHints/releases/download/v0.1.13/OldenEra-RetaliationHints-0.1.13.zip).
2. Полностью распакуйте архив в отдельную папку вне каталога игры. В корне находятся `Install.bat`, `Uninstall.bat` и папка `_files`.
3. Закройте игру и запустите `Install.bat` из корня распакованного архива.
4. Проверьте путь к папке с `HeroesOldenEra.exe`. Если найдено несколько копий, выберите нужную. Если игра не найдена, введите путь.
5. Подтвердите установку и дождитесь сообщения об успешном завершении.
6. Запустите игру через Steam.

Кнопка `Code / Download ZIP` создаёт архив исходников с папкой `OldenEra-RetaliationHints-main`. Ссылки `Source code` на странице выпуска также содержат исходники для разработки.

Для проверки целостности установочного ZIP сравните SHA-256 с соседним файлом `.zip.sha256`:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '<путь к архиву>'
```

DLL устанавливается в `BepInEx/plugins/RetaliationHints/OldenEra.RetaliationHints.dll`. Предыдущие файлы сохраняются в `BepInEx/RetaliationHints-backups/<дата-идентификатор>`. Старые дубликаты DLL внутри plugins также сохраняются в копии и убираются. Первый запуск с BepInEx занимает дополнительное время на создание библиотек.

При отличающемся загрузчике или отключённом `doorstop_config.ini` установщик останавливается с сообщением. При ошибке записи выполняется откат заменённых файлов.

## 3. Настройки

Файл `BepInEx/config/local.oldenera.retaliationhints.cfg` создаётся при первом запуске. Изменяйте его при закрытой игре и запускайте игру заново после сохранения.

- `Display.TextScale` задаёт масштаб текста от 0.7 до 1.8, по умолчанию 1.
- `Display.Enabled` задаёт видимость подсказок.
- `Diagnostics.CombatAudit` включает подробную сверку боевых событий, по умолчанию `false`.

Для обычного использования подробная сверка не требуется. Установщик сохраняет прежние настройки, включая включённую сверку. [Описание параметров](general.md) и [работа с журналами сверки](combat-audit.md).

## 4. Проверка работы

В `BepInEx/LogOutput.log` успешная загрузка отмечена строкой `Retaliation Hints 0.1.13 loaded`. В бою наведите курсор для обычной атаки: рядом со штатным прогнозом появляется оценка потерь, `Без контрудара` или `Потери: нет расчёта`. Проверьте также следующий бой.

Успешная загрузка не подтверждает точность прогноза. Подробная сверка сохраняет показанные значения и фактические события, но неполные и неоднозначные записи не считаются совпадениями.

## 5. Обновление и откат

Распакуйте новый установочный архив отдельно, закройте игру и запустите его `Install.bat`. Удалять старую версию перед обновлением не нужно. Настройки, журналы сверки, общие клавиши и другие моды сохраняются. При повторной установке совпадающей сборки появляется сообщение Ничего менять не нужно.

Установщик использует версию из своего архива. Для отката при закрытой игре верните прежнюю DLL из резервной копии в `BepInEx/plugins/RetaliationHints`. При необходимости восстановите `local.oldenera.retaliationhints.cfg`. Файл `backup.json` перечисляет сохранённые файлы. Резервные DLL хранятся вне plugins. Откат мода не меняет версию игры.

## 6. Удаление

Закройте игру и запустите `Uninstall.bat`. Проверьте путь и подтвердите удаление.

Удаление убирает копии `OldenEra.RetaliationHints.dll` внутри plugins. Настройки, журналы сверки, резервные копии, BepInEx и другие моды сохраняются. Интернет для удаления не нужен.

Для сброса настроек удалите только `BepInEx/config/local.oldenera.retaliationhints.cfg`. Журналы находятся отдельно в `BepInEx/RetaliationHints/CombatAudit/`; их можно удалить вручную после разбора. Без установочного архива удалите DLL мода и её дубликаты при закрытой игре.

## 7. Если возникла ошибка

| Сообщение или симптом | Действие |
|---|---|
| Это архив исходников RetaliationHints / Это исходники установщика | Скачайте установочный ZIP из раздела 2 и распакуйте целиком |
| Версия игры не подходит | Сверьте Steam build с требованиями |
| Другой или изменённый загрузчик | Укажите установленную версию BepInEx в обращении |
| Загрузка не удалась | Проверьте доступ к серверам BepInEx и повторите установку |
| Отказано в доступе | Закройте игру и проверьте право записи в папку |
| Нет подсказки | Проверьте журнал загрузки, Display.Enabled, штатный прогноз и следующий бой |
| Потери: нет расчёта | Прочитайте причину в журнале; это не нулевые потери |
| Реальные потери отличаются | Сверьте ограничения и приложите материалы из инструкции обратной связи |

Проверка совместимости без установки из корня распакованного архива:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\_files\Install.ps1 -GamePath '<папка игры>' -VerifyOnly -NonInteractive
```

В этом режиме нет скачивания и изменения файлов игры.
