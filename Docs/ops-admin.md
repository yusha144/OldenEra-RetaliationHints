# Установка и сопровождение Retaliation Hints

## 1. Требования и состав

Нужна собственная установленная игра Heroes of Might and Magic: Olden Era для Windows x64, Steam build 25672315, и BepInEx Unity.IL2CPP win-x64 6.0.0-be.788.

Загрузчик можно получить на [странице сборок BepInEx](https://builds.bepinex.dev/projects/bepinex_be). Для этой версии мода использована именно сборка 788. Общий порядок установки описан в [документации BepInEx](https://docs.bepinex.dev/master/articles/user_guide/installation/unity_il2cpp.html). После установки загрузчика самостоятельно запустите игру один раз для создания конфигурации и библиотек, затем закройте её. Не заменяйте уже настроенный другой загрузчик без проверки совместимости.

Архив мода содержит `BepInEx/plugins/RetaliationHints/OldenEra.RetaliationHints.dll`, документацию и `release-manifest.json`. Файлов самой игры, загрузчика и личных настроек в нём нет.

## 2. Установка

1. Скачайте `OldenEra-RetaliationHints-0.1.12.zip` из сообщения автора в Discord и соседний файл `.zip.sha256`. Если используете [Releases](https://github.com/Devourer22/OldenEra-RetaliationHints/releases), выбирайте готовый архив совместимой версии.
2. Сравните результат `Get-FileHash -Algorithm SHA256 -LiteralPath '<путь к архиву>'` с контрольной суммой. Автоматические архивы GitHub Source code содержат исходники; для установки нужен архив мода.
3. Закройте игру. Если раньше устанавливали этот мод, сохраните его DLL и конфигурацию в отдельную папку вне `BepInEx/plugins`.
4. Распакуйте архив в отдельную папку. Скопируйте каталог `BepInEx` из него в папку игры, где находится `HeroesOldenEra.exe`. Не оставляйте другую копию `OldenEra.RetaliationHints.dll` в иных подпапках `BepInEx/plugins`.
5. Запустите игру обычным способом. Проверьте сообщения мода в `BepInEx/LogOutput.log`.

Версия 0.1.12 является тестовой. Перед использованием прочитайте [ограничения](../README.md#ограничения-тестовой-версии). Разработчик может воспроизвести архив по [инструкции публикации](publishing.md).

## 3. Настройка

При закрытой игре откройте `BepInEx/config/local.oldenera.retaliationhints.cfg`. В секции `Display` параметр `Enabled = true` включает начальную видимость. Для отключения задайте `false`. Сохраните файл и снова запустите игру.

Отдельная горячая клавиша у этого мода не предусмотрена.

Подробная запись сверки `Diagnostics.CombatAudit` по умолчанию выключена. Для обычного использования её включать не требуется. Архив не заменяет конфигурацию: если раньше сверка была включена, она останется включённой.

[Остальные параметры и ограничения](general.md).

## 4. Проверка в игре

В бою наведите курсор для обычной атаки ближнего боя. Рядом со штатным прогнозом появится оценка потерь, Без контрудара или Потери: нет расчёта. Проверьте также следующий бой.

Успешная загрузка DLL не заменяет эту проверку. После обновления игры при отказе по контрольной сумме дождитесь совместимого выпуска; проверку сборки отключать не следует.

Для проверки точности включите [автоматическую сверку боя](combat-audit.md). Она сама сохранит прогноз, фактический урон и потери. Достаточно нескольких обычных атак с видимой подсказкой; удача и неудача исключаются из оценки.

## 5. Обновление и удаление

Для обновления закройте игру, сохраните текущую DLL и настройки вне папки плагинов, затем замените только каталог `BepInEx/plugins/RetaliationHints` файлами нового архива. Настройки остаются на месте. Проверьте журнал и сценарий из раздела 4.

Для отката при совместимой версии игры верните сохранённую DLL и её конфигурацию. Откат мода не восстанавливает прежнюю версию игры.

Для удаления при закрытой игре удалите каталог `BepInEx/plugins/RetaliationHints`. Файл `local.oldenera.retaliationhints.cfg` можно сохранить или удалить отдельно. Общий загрузчик, файл общих клавиш и остальные моды оставьте на месте.

## 6. Если подсказок нет

Проверьте наличие загрузчика, путь и отсутствие дубликатов DLL, `Display.Enabled`, совместимость игровых файлов и журнал. Надпись Потери: нет расчёта означает неподдерживаемый или неудавшийся расчёт, а не нулевые потери.
