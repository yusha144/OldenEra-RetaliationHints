# Справочник Retaliation Hints

## 1. Назначение и совместимость

Оценка потерь от ответного удара рядом с курсором атаки. Мод работает внутри игры через BepInEx IL2CPP. Поддерживаемая сборка: Steam 25672315, Unity 6000.0.66.

В `source/Plugin.cs` проверяются SHA-256 двух игровых файлов: `GameAssembly.dll` и `global-metadata.dat`. Если файлы не соответствуют ожидаемым, мод не включает свою функциональность. Обновление игры требует отдельной проверки и при необходимости адаптации кода.

## 2. Состав и поток данных

Plugin проверяет файлы игры и подключает обработчики Harmony. PreviewCapture связывает штатный прогноз с выбранной целью. NativeForecast обращается к игровому расчёту на отдельных расчётных данных, ForecastMath переводит урон в потери, RetaliationOverlay выводит результат у курсора.

`source/` содержит код, `tests/` содержит проверки правил и данных, `Build-Release.ps1` готовит архив. Игровые библиотеки находятся в собственной установленной игре и подключаются при сборке через параметр `GameRoot`.

Мод не изменяет сохранения и не запускает игровые действия для получения подсказок. В памяти хранятся временные данные отображения; отдельной базы данных нет.

## 3. Настройки

Файл в папке игры: `BepInEx/config/local.oldenera.retaliationhints.cfg`. Его создаёт BepInEx при первом запуске плагина. Обозначение `Секция.Параметр` в таблице означает параметр внутри указанной секции.

| Параметр | По умолчанию | Назначение |
|---|---|---|
| Display.Enabled | true | Начальная видимость подсказок |
| Display.TextScale | 1 | Масштаб текста; используемый диапазон 0.7-1.8 |

Отдельная горячая клавиша у этого мода не предусмотрена.

После ручного изменения настроек перезапустите игру. В архив не включаются личные конфигурации, поэтому при ручном обновлении DLL существующие настройки сохраняются.

## 4. Ограничения и ошибки

Это оценка текущего состояния. Полная цепочка срабатывающих эффектов, удача, неудача и все варианты лечения не моделируются. Поддерживается ограниченный вариант вампиризма. Известные неподдерживаемые случаи дают отказ от расчёта; числовой результат не является гарантией учёта всех событий боя.

Автоматические проверки охватывают выделенные правила и обработку данных. Они не подтверждают внешний вид, все игровые механики или сетевую совместимость. Проверка в игре остаётся отдельной частью подготовки выпуска.

## 5. Диагностика

В проверенном окружении сообщения BepInEx записываются в `BepInEx/LogOutput.log`. Ищите название мода и сообщения об отсутствии поддерживаемой сборки или ошибке запуска. При разборе ошибки сохраните сообщения мода из журнала.

В обращении укажите версию мода, Steam build, воспроизводимые действия и соответствующий фрагмент журнала. Перед публикацией журнала проверьте, нет ли в нём личных данных.
