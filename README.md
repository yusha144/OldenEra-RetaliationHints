# Retaliation Hints

Тестовая версия 0.1.12. Показывает рядом с курсором атаки, сколько существ может погибнуть от одного ответного удара. Помогает оценить риск без лишних переключений между отрядами и подсчётов в уме.

Автор: yusha144.

Для первого тестирования подготовлен отдельный архив `OldenEra-RetaliationHints-0.1.12.zip`. Его можно передать вложением в Discord. Архив содержит этот мод и инструкции; BepInEx устанавливается отдельно. Опубликованные через GitHub версии, если они доступны, находятся в [Releases](https://github.com/Devourer22/OldenEra-RetaliationHints/releases).

В бою мод показывает оценку потерь, `Без контрудара` или `Потери: нет расчёта`. Знак `~` означает приблизительный прогноз. Мод добавляет информацию на экран, не меняя правила боя и сохранения.

## Ограничения тестовой версии

Калькулятор оценивает один ответный удар по текущему состоянию отрядов. Некоторые эффекты он пока не учитывает:

- Удача и неудача намеренно исключены. Обычный разброс урона учитывается диапазоном.
- Изменения атаки и защиты от соседних отрядов после перемещения, в том числе бонусы Один за всех и Все за одного.
- Лечение и воскрешение до удара после перемещения, например поедание трупа чревнем.
- Полная цепочка повторных атак, отражения, реакций других отрядов и новых эффектов, возникающих во время действия.
- Все варианты защиты от гибели, специальных попаданий и лечения. Поддерживается ограниченный вариант вампиризма по одной цели.

При некоторых известных неподдерживаемых условиях мод показывает `Потери: нет расчёта`. Остальные сложные сочетания могут дать результат за пределами показанного диапазона. Нулевые потери не означают отсутствие ответного удара. Если важен исход атаки, учитывайте способности отрядов и эти ограничения.

Подробные журналы сверки по умолчанию выключены. Их можно включить для сообщения об ошибке. При обновлении существующая настройка сохраняется.

Требования: Windows x64, Heroes of Might and Magic: Olden Era, Steam build 25672315, BepInEx Unity.IL2CPP 6.0.0-be.788. Готовый архив содержит только этот мод и документацию. Загрузчик устанавливается отдельно.

В последнем проверенном сеансе 0.1.12 потери совпали в 36 пригодных для оценки действиях, но обычная ответка действительно состоялась только в двух. Зафиксированы пять расхождений первого урона при изменении состояния до удара. Эти результаты подходят для ограниченного тестирования, но не подтверждают точность всех механик или сетевую совместимость.

Исходники находятся в `source/`, автоматические проверки в `tests/`. Команда `Build-Release.ps1` собирает выбранный коммит в отдельной временной папке. Для разработки нужен .NET SDK 8 или новее, среда .NET 8 для проверок и библиотеки из своей установленной игры.

Для отдельного архива используйте инструкции из `Docs/`; общий установщик не требуется. Старые DLL сохранены в истории Git, новые сборки в неё не добавляются.

Лицензия авторского кода пока не выбрана. BepInEx и игровые библиотеки являются сторонними компонентами и в архив мода не входят.
