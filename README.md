# Retaliation Hints

Обновлено для сборки игры 26428102. Сборка и автономные проверки пройдены; проверка в настоящем бою ещё не выполнена. [Подробности совместимости](https://github.com/yusha144/OldenEra-RetaliationHints/blob/v0.1.16/development/compatibility-26428102.md).

**Тестовая версия 0.1.16. Неполный расчёт ответного удара.** Мод показывает приблизительный прогноз по текущему состоянию отрядов. Он не учитывает все механики боя: реальные потери могут выйти за показанный диапазон.

При наведении для атаки рядом с курсором появляется оценка количества существ, погибающих от одного ответного удара. Мод не изменяет правила боя и сохранения.

## Что означают подсказки

| Подсказка | Значение |
|---|---|
| `Потери ~ 2-5` | Оценка потерь от одной обычной ответки |
| `Потери до атаки ~ 2-5` | Оценка потерь от упреждающего удара врага |
| `Без контрудара` | Штатная проверка игры запрещает ответный удар |
| `Потери: нет расчёта` | Недостаточно данных, неподдерживаемое условие или ошибка расчёта |

Знак `~` обозначает приблизительную оценку. Нулевые потери не означают отсутствия контрудара. Отсутствие расчёта также не означает нулевые потери.

## Ограничения

- Удача и неудача исключены. Обычный разброс урона учитывается диапазоном.
- Изменения атаки и защиты из-за соседства после перемещения учитываются не полностью, в том числе Один за всех и Все за одного.
- Лечение и восстановление численности до удара после перемещения могут изменить результат, например поедание трупа чревнем.
- Повторные атаки, отражение, реакции других отрядов и новые эффекты во время действия не рассчитываются как полная цепочка.
- Вампиризм поддерживается только для ограниченного случая лечения собственной атаки по одной цели. Другие способы лечения, специальные попадания и защита от гибели покрыты не полностью.

Часть неподдерживаемых условий распознаётся и даёт `Потери: нет расчёта`. Другие сложные сочетания могут дать неточный числовой прогноз. Подсказка оценивает одну ответку, а не суммарные потери за всё действие.

## Статус проверки

В записанном сеансе 0.1.12 потери совпали в 36 пригодных для оценки действиях, но обычная ответка состоялась только в двух. В пяти действиях первый урон вышел за прогноз; причины всех расхождений полностью не установлены. Это ограниченные наблюдения, не подтверждение точности всех механик.

Версия 0.1.16 восстанавливает обращения к прогнозу, подсказке и событиям боя для сборки 26428102. Для ответного урона используется текущий игровой расчёт. Новая версия ещё не проверена в настоящем бою. Подробная сверка по умолчанию выключена; существующая настройка при обновлении сохраняется.
